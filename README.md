# Nocta 🌙

**Calm Your Night**

A minimal sleep sound app built with Expo and React Native.

## Features

- 🎵 10 curated sleep sounds (nature, white noise, ambient)
- 🎚️ Sound mixing with individual volume controls
- ⏱️ Sleep timer (15/30/45/60 minutes)
- 💾 Save and load custom sound scenes
- 🔄 Background audio playback

## Quick Start

```bash
cd nocta
npm install
npm start
```

Then press:
- `i` for iOS simulator
- `a` for Android emulator
- `w` for web

## Sound Categories

**Nature** 🌧🌊🌲🔥🍃
- Rain, Ocean, Forest, Fire, Wind

**White Noise** ⚪🩷🟤
- White, Pink, Brown

**Ambient** ☕🚆
- Cafe, Train

## Usage

1. Open the app and tap "Start Mixing"
2. Select sounds to play
3. Adjust volume sliders for each sound
4. Set a sleep timer
5. Save your favorite combinations as scenes

## Tech Stack

- Expo
- React Native
- expo-av (audio)
- React Navigation
