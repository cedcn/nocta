# Nocta 🌙

**Sleep Sounds App - Complete XMSLEEP Feature Replication**

A comprehensive sleep sound app built with Expo and React Native, replicating all features from XMSLEEP.

## ✨ Features

### 🎵 Audio Features
- **100+ White Noise Sounds**: Nature, rain, animals, urban, places, transport, things, and noise categories
- **Remote Audio Loading**: Sounds loaded from GitHub repository
- **Seamless Loop Playback**: Continuous audio without gaps
- **Individual Volume Control**: Adjust each sound independently
- **Volume Persistence**: Volume settings saved across app restarts
- **Multiple Sounds**: Play up to 10 sounds simultaneously

### 🎨 Interface & Experience
- **Category Navigation**: Browse sounds by 8 different categories
- **Material Design**: Clean, modern UI with dark theme
- **Favorites System**: Save your favorite sounds with ❤️
- **Floating Play Button**: Quick access to currently playing sounds
- **Smooth Animations**: Polished user experience

### ⚙️ Practical Features
- **Timer Function**: Auto-stop after 15/30/45/60 minutes with countdown
- **3 Presets**: Save up to 10 sounds per preset, quick scene switching
- **Daily Quotes**: Inspirational quotes with sharing capability
- **Settings Panel**: App configuration and information

## 📱 Screens

1. **Home** - Browse sounds by category
2. **Mixer** - Mix sounds with presets and timer
3. **Favorites** - Quick access to favorite sounds
4. **Quotes** - Daily inspirational quotes
5. **Settings** - App settings and information

## 🛠️ Tech Stack

- **Expo** ~55.0.6
- **React Native** 0.83.2
- **expo-av** - Audio playback engine
- **React Navigation** - Screen navigation
- **AsyncStorage** - Data persistence
- **TypeScript** - Type safety

## 📦 Sound Categories

- **Nature** (自然): River, Waves, Campfire, Wind, Waterfall, etc.
- **Rain** (雨声): Light Rain, Heavy Rain, Rain on Window, Thunder, etc.
- **Animals** (动物): Birds, Cats, Crickets, Frogs, etc.
- **Urban** (城市): City, Traffic, Construction, etc.
- **Places** (场所): Cafe, Library, Restaurant, etc.
- **Transport** (交通): Train, Airplane, Car, Boat, etc.
- **Things** (物品): Fan, Clock, Keyboard, Typewriter, etc.
- **Noise** (噪音): White, Pink, Brown noise, etc.

## 📖 Usage

### Playing Sounds
1. Select a category from the horizontal scroll
2. Tap any sound card to start/stop playback
3. Adjust volume using the slider when playing
4. Tap ❤️ to add to favorites

### Using Presets
1. Play your desired sounds
2. Long-press a preset slot (1/2/3) to save
3. Tap a preset to load saved sounds
4. Each preset can hold up to 10 sounds

### Setting Timer
1. Go to Mixer screen
2. Tap timer duration (15/30/45/60 minutes)
3. Watch countdown in real-time
4. Sounds auto-stop when timer ends
